# Bodies to test — every named body in the scene

**Total: 684 named bodies** — 192 bodies (the Sun, planets, dwarf worlds, asteroids, comets, Trojans, Centaurs and the rest) and 492 moons.
Plus **38,422 near-Earth asteroids** drawn as stamped rocks; they appear only when you fly near them, so they are not listed one by one.

Generated from the board's own list (`node scripts/list-bodies.mjs`), so it matches **All bodies** exactly.

How to test one: open **All bodies**, type its name in **Find**, and click it. The camera flies there and its card opens. Check that:
- it has a surface, not a plain ball;
- its card has real numbers;
- it turns;
- any moon goes round it.

For moons, open the planet's **N moons** button.
