# sharp-spike.txt: which paragraph is which event

`sharp-spike.txt` (project root) holds only the words to record, one paragraph per clip, separated by a blank line, like the `Part 3*.txt` files. This file says which event each paragraph belongs to, in order, so the clips can be wired up once recorded.

| # | Event id (stories.js) | Why |
|---|---|---|
| 1 | `supermoon` | The old clip has a sharp audio spike; new text follows the new animation (oval orbit, apogee and perigee, side by side). |
| 2 | `leonid-storm-1833` | The old clip has a sharp spike; new text explains the comet, its dust trail and Earth crossing it. |
| 3 | `precession` | New, longer text: Polaris and pole stars explained first. |
| 4 | `zodiacal-light` | New, longer text: where and when to look, and what kind of light it is. |

Recording notes: same voice and pace as the other catalogue clips; numbers read as written; listen for clipping on hard consonants ("k" in "kilometres", "t" in "Tempel–Tuttle").

Until the new clips exist, `stories.js` keeps the old text so the words on screen and the voice still match.
